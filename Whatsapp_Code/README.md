# Whattsapp Bot to send messages

First use ID_assigner.py on your friends list to assign a unique code identifier to each of them. This creates a new .csv file with the "_code" ending. 

Then use message_type_assigner.py to assign the type of message (Basic or Personalised) you will send to each of your friends randomly. 

Finally, use send_messages.py on the final friends list to send the messages using a whatssapp bot on Whattsapp Web.
